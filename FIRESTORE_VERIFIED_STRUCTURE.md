## Firestore Security Rules (VERIFIED)

**Source:** `firestore.rules` (full file 218 lines)

### Summary by Collection

#### `users/{uid}`
- **Read:** Own document only (`isOwner(uid)`)
- **Create:** Own document, requires name/email validation
- **Update:** Own document, uid/userId/createdAt/provider immutable
- **Delete:** Forbidden

#### `devices_meta/{docId}`
- **Read:** Owner OR member (via members collection existence check)
- **Create:** Authenticated, ownerId must be self
- **Update:** Owner only, ownerId/deviceId immutable
- **Delete:** Owner only

#### `members/{docId}`
- **Read:** Self OR device owner
- **Create:** Authenticated (5-member limit enforced in app layer, not rules)
- **Update:** deviceId/uid/userId immutable, role must be owner|member
- **Delete:** Self OR device owner

#### `activity_logs/{docId}`
- **Read:** Authenticated (scoped at query level by deviceId)
- **Create:** Authenticated, requires deviceId/action/performedBy
- **Update:** Forbidden
- **Delete:** Forbidden

#### `device_analytics/{docId}`
- **Read:** Authenticated (scoped at query level)
- **Create:** Authenticated, date must match YYYY-MM-DD format
- **Update:** Authenticated, deviceId/date immutable
- **Delete:** Forbidden

#### `dex_bots/{dexBotId}`
- **Read:** Owner only
- **Create:** Owner only, ownerId must be self
- **Update:** Owner only, ownerId/dexBotId immutable, currentMessage max 128 chars, currentEmotion whitelist
- **Delete:** Owner only

#### Default
- **All:** Forbidden (explicit deny-all rule at end)
